Sistema de lectura QR, reconocimiento de respuestas y registro de notas.

1. Conexión con Google Sheets

Apps Script configurado

La conexión requiere que la implementación de Apps Script esté publicada, autorizada y tenga el código servidor compatible con esta página.

2. Capturar la hoja del examen

Coloca toda la hoja dentro de la imagen, con buena iluminación, sin sombras y con el código QR visible.

3. Información del estudiante y examen

Formato esperado: RUDE|CURSO|CODIGO|COLUMNA. Ejemplo ilustrativo: 12345|3ro A FIS|EX01|BP. Utiliza los datos reales configurados en tu sistema.

4. Revisar las respuestas

Selecciona la respuesta de cada pregunta. La lectura automática es una ayuda y debes verificar las marcas antes de calcular.

5. Resultado de la corrección

Sistema preparado. Captura una imagen o introduce los datos para comenzar.
